# PRERAMID 3D

เกม Godot 4.3+ แบบสามมิติมุมมองบุคคลที่หนึ่ง ขนอิฐจากกองไปยังพีระมิด **ทีละก้อน** จนครบ 819 ก้อน (13 ชั้น) พีระมิดจะค่อย ๆ สูงขึ้นตามอิฐที่วาง โหมด Hard ออกแบบให้ใช้เวลาประมาณ 5 ชั่วโมงเมื่อเดินขนต่อเนื่อง เวลาจริงขึ้นอยู่กับการเล่น ส่วน Normal มีตัวช่วยเพิ่มความเร็ว

ภาพใช้แสงช่วงเย็นและสีทะเลทรายที่นุ่มลง พื้น ทางเดิน และอิฐมีเท็กซ์เจอร์ที่สร้างจากโค้ด พร้อมฝุ่นทรายปลิวและหมอกพายุที่หนาขึ้นเป็นระยะ มีเสียงตอบสนองเมื่อหยิบ วาง ซื้อของ และสร้างชั้นสำเร็จ ฟอนต์ไทยใช้ Noto Sans Thai Looped ภายใต้ SIL Open Font License

## วิธีเล่น

เปิด `project.godot` ด้วย Godot แล้วกด F5 เลือก Normal หรือ Hard

- เมาส์: หันมองรอบตัว (เคอร์เซอร์จะถูกจับไว้ขณะเล่น)
- WASD / ปุ่มลูกศร: เดินตามทิศที่มอง
- E หรือ Space: หยิบอิฐที่วงแหวนกองอิฐ / วางอิฐที่วงแหวนจุดก่อสร้าง
- B: เปิดหรือปิดร้านตัวช่วย (Normal เท่านั้น)
- M: เปิดหรือปิดเสียง
- P: พักเกมและปรับระดับเสียงหรือความไวเมาส์ (เวลาจะหยุดนับ)
- Esc: กลับเมนูและปล่อยเคอร์เซอร์

ข้อความด้านบนบอกทิศทางและระยะถึงจุดที่ต้องไป Normal ซื้อรองเท้าเร็ว รถเข็นอิฐ และผ้าคลุมกันลมด้วยเหรียญที่ได้จากการวางอิฐ รถเข็นช่วยให้เดินเร็วขึ้นขณะถืออิฐ ผ้าคลุมช่วยลดแรงลมพายุ ยังถืออิฐได้เพียงครั้งละหนึ่งก้อน Hard ไม่มีร้านหรือตัวช่วย เมื่อสร้างแต่ละชั้นเสร็จจะได้รับโบนัส 10 เหรียญ

HUD บอกจำนวนก้อนที่เหลือก่อนขึ้นชั้นใหม่ ทุก 25 ก้อนมีข้อความฉลอง และเมื่อครบ 819 ก้อนจะแสดงเวลาที่ใช้กับโหมดที่เล่น

## เล่นบนเว็บ

Web export อยู่ในโฟลเดอร์ `docs/` และใช้ GitHub Pages เผยแพร่ที่ https://ouaneng.github.io/PRERAMID/ แนะนำเบราว์เซอร์เดสก์ท็อปที่รองรับ WebGL 2.0 เซฟบนเว็บเก็บในเบราว์เซอร์ของเครื่องนั้น แยกจากเซฟเกมบน Windows

เกมบันทึกอัตโนมัติแยกตามโหมดที่ `user://preramid_normal.json` และ `user://preramid_hard.json` โดยบันทึกจำนวนอิฐ เวลาที่เล่น เหรียญ และตัวช่วย การตั้งค่าเสียงกับเมาส์บันทึกใน `user://preramid_settings.json`
